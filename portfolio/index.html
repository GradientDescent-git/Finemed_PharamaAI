Finemed PharmaAI — Demand Intelligence Platform

Finemed PharmaAI

Real-World Pharmaceutical ERP Demand Intelligence & ML Forecasting Engine

✓ Live Deployed & Production Hardened

The Business Problem

Pharmaceutical distributors manage thousands of fast-moving and intermittent demand medicines across historical dBase ERP exports (`.DAT` files). Unvalidated updates cause severe inventory stockouts, while generic LLMs hallucinate pricing and quantities.

Production Architecture Solution

  • Hybrid Forecasting Engine: Intermittent TSB (Teunter-Syntetos-Babai) model paired with zero-shot foundation model Chronos-2 P50 probabilistic quantiles.
  • Evidence-Only Validation Routing: Chronos-2 P50 selected ONLY when validation advantage ≥ 30% over TSB; zero holdout data leakage.
  • Atomic Publication Gate: Candidate forecasts write to versioned run directories (`/forecast.parquet`). Production data (`latest.parquet`) is promoted ONLY after batch validation succeeds.
  • 100% Grounded LLM Orchestrator: LLM parses natural-language intent ONLY. All numerical facts originate from a deterministic query service.

Enterprise System Capabilities

  • 5-Step Async Data Pipeline UI: Interactive operator controller for monthly DAT package upload, validation, background forecasting, and store reload.
  • Dark Finemed Product UI: 7 complete tabs (Assistant, Overview, Forecasts, Demand Rankings, Data Pipeline, Operations, Settings).
  • Security Hardening: Constant-time HMAC authentication (`hmac.compare_digest`), zip-bomb expansion defense, and path-traversal protection.
  • 97 Passing Test Suites: 100% portable test suite passing cleanly on fresh clones without pre-existing data.
